\chapter{Metodología}
\section{Recolección de muestras}
Las muestras se recolectaron a través de un sistema de captura y condensación.
El sistema está compuesto por un refrigerador modificado marca Hisense, con
una conexión de tubería de PVC en su interior. El sistema estaba adaptado 
a un \textit{timer} para el funcionamiento automático del sistema (Fig \ref{fig:refri}). 

\begin{figure}[H]
    \centering
    \includegraphics[width=0.85\textwidth]{Resultados/Sistema_refri.png}
    \caption{Esquema del sistema de captura y condensación para el muestreo
    de vapor de agua.}
    \label{fig:refri}
\end{figure}

Para obtener un factor del fraccionamiento isotópico que se produce al
condensar la muestra, se adapta el condensador a una cámara de
ambientes controlados. Cada 24 horas se recolecta la muestra de vapor y
una muestra líquida. La cabina mantenía las condiciones en
$30\,^{\circ}\mathrm{C}$ y $30\%$ de humedad relativa.

\section{Análisis de $\delta^{2}$H y $\delta^{18}$O}
\label{sec:analisis_isotopico_metodo}

Para estimar el porcentaje de mezcla entre el vapor de fondo (atmosférico) y 
el vapor teórico de combustión, se empleó un modelo de mezcla binaria de dos 
extremos en el espacio $\delta$D--$\delta^{18}$O. El extremo de fondo no se
definió como un punto fijo, sino mediante la línea meteórica regional (LMR),
$\delta D = a\,\delta^{18}O + b$, donde $a$ y $b$ corresponden a la 
pendiente y ordenada al origen de dicha recta. El extremo de combustión se
fijó en los valores isotópicos teóricos $\delta^{18}O_c$ y $\delta D_c$.

Para cada muestra ($\delta^{18}O_s$, $\delta D_s$) se determinó su punto de
fondo específico ($\delta^{18}O_{bg}$, $\delta D_{bg}$) mediante la intersección 
entre la LMR y la recta que une la muestra con el extremo de combustión. 
Primero se calculó la pendiente de dicha recta:

\begin{equation}
m_{sc} = \frac{\delta D_s - \delta D_c}{\delta^{18}O_s - \delta^{18}O_c}
\end{equation}

y, a partir de esta, las coordenadas del punto de fondo:

\begin{align}
\delta^{18}O_{bg} &= \frac{\delta D_c - m_{sc}\,\delta^{18}O_c - b}{a - m_{sc}} \\
\delta D_{bg} &= a\,\delta^{18}O_{bg} + b
\end{align}

El porcentaje de mezcla (contribución del vapor de combustión) para 
cada muestra se calculó de forma independiente a partir de ambos isótopos,

\begin{equation}
\% = \frac{\delta^{18}O_s - \delta^{18}O_{bg}}{\delta^{18}O_c - \delta^{18}O_{bg}} \times 100 \;=\; \frac{\delta D_s - \delta D_{bg}}{\delta D_c - \delta D_{bg}} \times 100,
\end{equation}

donde la coincidencia entre ambos valores se utilizó como criterio de 
consistencia del modelo de mezcla. Finalmente, para la representación 
gráfica se generaron las líneas de mezcla correspondientes a fracciones
de combustión de $p = 0.2,\,0.4,\,0.6,\,0.8$, mediante interpolación lineal 
entre cada punto de fondo y el extremo de combustión:

\begin{align}
O_p &= \delta^{18}O_{bg} + p\,(\delta^{18}O_c - \delta^{18}O_{bg}) \\
D_p &= \delta D_{bg} + p\,(\delta D_c - \delta D_{bg})
\end{align}

Para evaluar los datos estadísticamente se utilizó un análisis de datos
atípicos a través del cálculo de la anomalía estandarizada ($z$). Este
parámetro se calcula restando la media muestral de los datos brutos $x$
y dividiendo el resultado por la desviación estándar muestral
correspondiente (Ecuación~\ref{eq:z_score}).

\begin{equation}
z = \frac{x - \bar{x}}{s_x}
\label{eq:z_score}
\end{equation}

Se considera dato atípico cuando $|z| > 2$ y $|z| > 3$. En el primer
caso, se categorizan como sospechosos, mientras que en el segundo caso
se etiquetan como dato extremo.

Asimismo, se realizó una prueba de valores extremos mediante el rango
intercuartílico (Ecuación~\ref{eq:iqr}).

\begin{equation}
\mathrm{IQR} = Q_3 - Q_1
\label{eq:iqr}
\end{equation}

Se consideran datos atípicos aquellos que quedan fuera del rango
definido en la Ecuación~\ref{eq:rango_atipicos}. En tal caso, se
etiquetaron como valores extremos.

\begin{equation}
Q_1 - 1.5\,\mathrm{IQR} \le X \le Q_3 + 1.5\,\mathrm{IQR}
\label{eq:rango_atipicos}
\end{equation}

\subsection{Evaluación de la normalidad de las variables de las estaciones de calidad 
del aire}
\label{subsec:normalidad}

Para seleccionar las pruebas estadísticas para el análisis de los 
datos de las estaciones de monitoreo de calidad del aire (CR, NATIVITAS y DIF), 
se evaluó si cada variable seguía una distribución normal, con el fin de decidir 
entre un enfoque paramétrico y uno no paramétrico. El análisis se realizó con series 
horarias correspondientes a ambas campañas de muestreo (20 de febrero al 5 de marzo y 
de 25 al 29 de mayo de 2026), a través de los datos validados. 

Se evaluaron los contaminantes criterio (O$_3$, SO$_2$, CO, NO$_2$, PM$_{10}$ y PM$_{2.5}$) 
y las variables meteorológicas disponibles en cada estación (velocidad del viento, 
temperatura, presión barométrica, humedad relativa). La dirección del viento (WD) se 
excluyó del análisis porque es una variable circular (0--360$^\circ$) y el supuesto de 
normalidad no es aplicable. 


Para cada variable se aplicaron tres pruebas de bondad de ajuste con hipótesis nula 
de normalidad: Shapiro-Wilk, Lilliefors y Anderson-Darling. Se utilizó un nivel de significancia $\alpha = 0.05$ 
y se consideró que una variable cumplía el supuesto de normalidad únicamente si ninguna de 
las tres pruebas rechazaba la hipótesis nula ($p > 0.05$ en todas). Este criterio conservador 
se adoptó debido a que, con muestras de tamaño moderado, las pruebas pueden discrepar entre sí.

De manera complementaria, se calcularon el coeficiente de asimetría y la curtosis de 
cada variable (para una distribución normal, 0 y 3, respectivamente) y se construyeron 
gráficos cuantil-cuantil (Q-Q) contra la distribución normal estándar, que permitieron 
identificar el tipo de desviación.

\subsection{Análisis de correlación entre variables}
\label{subsec:correlacion}

Para explorar las relaciones entre los contaminantes y las variables meteorológicas se 
calcularon matrices de correlación de Spearman, por separado para cada campaña de muestreo 
y para cada estación (CR, NATIVITAS y DIF). Se incluyeron O$_3$, SO$_2$, CO, NO$_2$,
PM$_{10}$, PM$_{2.5}$, la velocidad del viento (WS), la temperatura, la presión barométrica
(PBAR), la humedad relativa (HR) y, en la estación DIF, la radiación ultravioleta
(UV), según la disponibilidad de cada variable en cada estación. La dirección del 
viento se excluyó por tratarse de una variable circular. Cada coeficiente se calculó 
con todas las horas con dato válido para el par de variables correspondiente 
(eliminación por pares), y se consideró significativo cuando el valor de $p$ fue menor, con 
corrección de Benjamini-Hochberg, a $\alpha = 0.05$. Las matrices se representaron como mapas de 
calor del triángulo inferior, con una escala divergente entre $-1$ y $1$. Se consideró 
que $|\rho| < 0.3$ indica una correlación 
débil, entre 0.3 y 0.7 una correlación moderada y mayor a 0.7 una correlación fuerte.
El análisis se realizó en dos escenarios. En el primero se utilizaron todas 
las horas de cada campaña. En el segundo se consideraron únicamente las horas 
del periodo nocturno de muestreo, de las 22:00 a las 02:00 h.
